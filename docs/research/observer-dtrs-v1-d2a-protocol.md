## 1. 固定研究对象与可主张范围

样本仍为 $x=(g,t,w,i)$，其中 $w$ 为 PRE 的存活发言狼人，$i$ 为存活非狼观察者。
$W_t=K_W\cap A_t$，目标保持：

\[
Y_x=\mathbf1\{\widetilde S_{t,i}\cap W_t\ne\varnothing\}.
\]

成功非空报告保留原支持；成功空报告的有效集合为六名非自身玩家，故本论域中 Y=1；
失败/缺失不产生正式标签。只怀疑死亡狼人而未命中存活狼人仍为 Y=0。
本阶段不改变 DTRS 将来对隐藏认知状态的接受/暂缓/拒绝语义。

Q 是规范化嫌疑分配质量，既非身份概率，也非本事件概率。Q 保留死亡列的
原始七座位质量，`r=s+m` 只汇总存活狼人列；不能直接把 r 当成 $P(Y=1)$。
本阶段估计的是特定抽样测度、固定 ToM 来源和粗化条件属性下的
$p_C=P(Y=1\mid C, f_k)$，不等同于掌握全部公开历史时的后验。

正式数据锚点：

```text
/data/yuxiao/Untrusted_Network_Simulation/observer-dtrs/datasets/paper-development-qwen35-9b-1500-v1-observer-dtrs-v1
d25537be18da93ddc2f49be695f876db2edef5f31904fea0999a292f491abfa3
```

共 1500 局、22685 条样本、19296 正类、3389 负类。它是已经探索过的 development
publication；本轮所有验证应称**固定 ToM 来源下的下游开发验证**，不能称未触碰的
端到端独立测试。正式泛化主张还需要新的隔离游戏或包含全部选择步骤的严格外层设计。

## 2. 已验证的跨层依赖与推荐划分

### 2.1 来源事实

从正式数据集受限元数据证明重新核对：五个 $F_k$ 各 300 局；Qwen3 $f_k$ 的
训练游戏恰为另外 1200 局，训练/held-out 交集均为 0。五个 terminal 均为固定
25200 optimizer steps 的封存元数据，训练源码版本为 `ebf98b7e3249f78d3f1fa1fd46c20affe0486913`。
数据集读取验证通过，未读取权重或重新运行 ToM。

对 $k\ne l$，$|F_k\cap Train(f_l)|=300$；对角项为 0。因此直接将全部 OOF
特征混合后再划分 DTRS 训练/测试，存在如下路径：

```mermaid
flowchart LR
  B[测试游戏 b 属于 Fk 的 ToM 报告监督] --> FL[其他折 ToM fl 的训练]
  FL --> QA[训练游戏 a 属于 Fl 的预测 Q]
  QA --> D[DTRS 拟合]
  D --> E[对 b 的下游评价]
```

ToM 监督与 Y 并非同一个标签，但都涉及该局报告/隐状态。单条 Q 是 OOF，不能
切断这个路径；存在依赖不意味着分数必然改善，但不足以支持严格端到端隔离。

另核对了公开预处理：`backbone_study.py:prepare_study` 用全 publication 最大 day
建立时间表；实际 max_day=4。`tom/temporal.py` 的 day 正弦公式不含数据拟合参数，
最大 day 仅决定表长，并不重标定已存在的 day 编码。这不是已发现的监督泄漏，
但依然应记录其覆盖域；新游戏的超范围 day/长度不能事后静默删除。

既有 evaluation 同时比较 gpt2/qwen2/qwen3/gemma3_text。训练清单及固定 terminal
能够证明训练排除，却不能证明 Qwen3 的选择、其他超参数或研究设计从未参考
全部 1500 局的 OOF 成绩。本轮不将这一未验证事项包装成独立泛化证明。

**另外已确认一条历史数值控制依赖，不能仅以训练游戏交集为零排除。** 在上述
`ebf98b7` 真实历史源码中，`tom/backbone_execution.py:_binding` 的
`training_rng.study` 为 preparation manifest 摘要；`_reset_rng` 把
`digest_fields("backbone_training_rng_v1", training_rng)` 转为 32 位数值 seed，
用于 Python/NumPy/Torch 的训练 RNG。该 preparation 又绑定全量 publication，
publication 文件哈希包含 held-out 的 BeliefObservation 报告。因此存在：

```text
held-out 报告 → publication 摘要 → preparation 摘要
              → training_rng.study → 数值训练 seed → 随机训练过程
```

实际五折绑定及派生 seed 已保存到诊断 JSON 的 `historical_training_rng`。
例如 fold 0 的 `study=f4ff8837...`、`protocol_seed=8223107198166168390`。
这说明历史训练不满足“仅改变 held-out 监督，不影响任何数值训练控制”的强非干预
条件；它不是只用于日志的哈希。初始模型参数的 seed 另有绑定，这里确认的是训练
RNG 路径，不能混称初始化权重已读入报告。

哈希的机械依赖**不等于已证明模型有效利用测试标签，也不证明乐观偏差的方向或
大小**。本轮没有重训，未比较替换 seed 后的权重/分数。冻结 ToM、D1 数据及目标
保持不变；该发现进入统计来源限制，而不是静默修补历史产物或更改研究语义。

### 2.2 推荐：每个 ToM held-out 内嵌套整局验证

对每个 $k=0,\ldots,4$ 单独进行：

1. 固定 $f_k$ 及其 300 局 $F_k$；DTRS 的所有训练、验证和测试均限于 $F_k$。
2. 外层按完整游戏做 5 折：每次 240 局训练、60 局测试。
3. 外层 240 局内再做 3 折：每次 160 局拟合、80 局选择；每次重新学习分箱、
   支持度合并、层级概率，禁止预先用全部 240 局生成内层边界。
4. 选参后用全部外层 240 局重新学习边界并拟合，对 60 局一次性预测。
5. 合计 25 个外层测试块。每个游戏/样本恰有一次下游外层预测，共 1500 局；
   不把同一游戏的 PRE 或观察者拆到不同集合。

分割只依赖固定协议 seed、来源 fold 和游戏 ID，不按记录、正负类、报告状态或模型分数平衡。
将 canonical JSON 数组
`[domain,20261014,tom_fold,parent_outer_or_null,game_id]` 做 SHA-256，
按 `(digest,game_id)` 排序，rank mod K 分配。外层 K=5、parent=null；内层 K=3、
parent=外层编号。domain 固定为 `observer-dtrs-d2-development-split-v1`，不搜索 seed。
dataset 摘要另作身份锚点，**不参与数值 seed 或划分排序**；这样来源校验与训练控制
分离，避免在新协议中复制历史 RNG 依赖。固定游戏 ID 和 fold 的前提下，改变监督
及其来源哈希不得改变 D2 划分。源 ToM 的原有 fold 本轮冻结，不重新设计。
本轮只做支持度预览，外层 assignment 摘要为
`99c50a8125559022823f6084c8f456601f93ed9c0620f6b0ceef7cf0b17a80f4`。
确认协议后再发布完整 split manifest，不把预览当正式实验结果。

### 2.3 代价与边界

- 每个模型仅用 240 局而不是混用全部 1500 局，内层仅 160 局，稀疏 PK 粒必须回退。
- 概率映射必须与对应 $f_k$ 成对保存；不同 fold 的 r 边界和粒编号不能直接混用。
  最终若采用另一 ToM checkpoint 或全量训练 ToM，不能直接声称这套映射已验证。
- 五个 ToM 训练集合彼此重叠，不是五次独立重复实验。汇总评分可以覆盖 1500 局，
  但不能把 fold 间波动直接当 5 个独立样本估标准误。
- 本设计切断经其他 fold 训练输入的直接跨层路径；**不能切断已封存 ToM 的全量
  哈希→训练 RNG 路径**，也不消除历史架构选择、development 探索及分析者选择效应。
- 在未来所有数值控制、训练与选择均独立于测试监督的前提下，这种结构可评价
  “ToM 1200 局 + 独立映射 240 局”的分阶段流程。当前来源不满足该强前提，
  所以本方案仅支持固定历史产物下的下游开发比较，不能改称严格端到端交叉拟合。
- 更便宜的单次 240/60 划分会浪费开发评价覆盖并增加划分偶然性；推荐保留嵌套方案。

`.1588/.3573/.7259`；游戏加权对应 `.1504/.3519/.7175`。
discussion×2 在 `[.3,.4)` 内有 6290 条，其中 4216 条是成功空报告。

关系必然非单调，但不足以支持强加单调约束。成功空报告、支持集合大小等未观察
状态会被同一 r 信息粒混合；r 不是事件概率。

预览的稀疏性：

- PK×1 外层训练每块仅 15–31 局、1–10 条负类；外层测试每块仅 1–10 局。
  25 个外层测试块中有 11 个没有该组负类。
- PK×2 外层测试有 7/25 块没有负类。
- 75 个内层训练块中，PK×1 有 5 块、PK×2 有 4 块无负类。
- PK×1 内层训练组仅 7–23 局；固定切成五个细粒通常无法达到每粒十局支持。
- ToM fold 0 的 PK×1 负类只来自 3 局，少于 5 个外层块；即使标签分层，也无法
  保证每个测试块有负类。因此不以此为理由搜索 seed 或重复抽取“好看”的划分。

这些块必须保留。Brier/Log Loss 在单类别测试组仍有定义；不得删掉它们或重抽
seed。AUROC 若将来报告应为 NA，不能通过删局改变主评价人口。

## 4. 统计测度：权重也是概率目标的一部分

令 $n_g$ 为该局**全部**合法观察者样本数。本数据每局为 4–34 条，中位数 16。

- 记录等权：从全部记录中均匀抽一条，长局出现概率更大。
- 游戏等权：先均匀抽一局，再在该局均匀抽一条。推荐作为主目标，便于游戏级比较。

两者已产生不同基率：记录等权 .8506061，游戏等权 .8408461。后者不是简单修改
误差条，而是改变了估计的条件概率测度，须在实施前明确接受。
概率测度条件于 canonical 报告完整且 n_g>0 的研究游戏，当前全部 1500 局满足。
未来零机会或采集失败游戏须另计覆盖，不能静默置零后宣称评估了所有运行对局。

对当前训练游戏集合 T，令 $u_{gj}=1/n_g$，则 $\sum_{gj}u_{gj}=|T|$。
对信息粒 C：

\[
E_C=\sum_{g\in T,j}u_{gj}1\{x_{gj}\in C\},\quad
S_C=\sum_{g\in T,j}u_{gj}1\{x_{gj}\in C\}Y_{gj},\quad
\widehat p_C=S_C/E_C.
\]

禁止在每个粒内改用 $1/n_{g,C}$，那会改成“先等权选含该粒的游戏”的另一条件
分布。n_g 仅是离线权重和评价分母，不是在线属性，也不需要运行时预知全局长度。
记录等权敏感性分析可用 $u^{rec}_{gj}=|T|/N_T$，使总权重仍为 |T|，避免仅因
权重缩放改变平滑强度；其主评价人口为记录分布，应单独标记。
不做正负类过采样或 class weight 来“纠正不平衡”，否则又改变校准目标。

每粒同时记录行数、distinct games、正/负类游戏数、E_C 和
$H_C=(\sum_g a_{gC})^2/\sum_g a_{gC}^2$，其中 $a_{gC}=n_{gC}/n_g$。
H_C 是按游戏质量的 Kish 支持诊断，不是严格的独立伯努利样本量或后验自由度。

## 5. 条件属性与信息粒

旧 Phase2 的 M0–M3 是候选目标/Theta_AC 的 L2 Logistic Mapper；本协议的简称
M0/M1 必须带 `OBS` 前缀，不复用旧函数、模型文件或论文表号。

| 新模型 ID | 条件属性 | 用途 |
| --- | --- | --- |
| OBS-EQ0（本轮 M0） | phase × nW | 主基线 |
| OBS-EQ1（本轮 M1） | phase × nW × train-only bin(r) | 主比较 |
| OBS-EQ2-dW | M1 + train-only bin(dW)，仅双狼适用 | 扩展候选，不进入主检验 |
| OBS-EQ3-acting_share | M1 + train-only bin(s/r)，r=0 单独状态 | 替代扩展，暂不冻结网格 |

单狼 m=0、dW=None 是结构性不适用，不填零后与双狼零差异混合。
s/m/r/dW 存在确定性冗余，不建议一次把所有属性笛卡尔积交叉；当前 PK 支持不足。
真实空报告标记、原始/有效嫌疑集合、target q、Theta_AC 不得作为条件属性。
离线拟合和评价必须显式接收 D1 的 Y；“不得输入监督”约束指预测属性接口，
不禁止用训练 Y 估计概率。真实报告集合仅限受控标签构造与审计，不进入拟合属性。

明确地，在同一个固定 f_k 和当前训练游戏 T 内，令
$b_x=(phase_x,nW_x)$、$C_0(x)=b_x$、$C_{1,T}(x)=(b_x,h_{T,b_x}(r_x))$。
等价关系为 $x\sim_{T,M}z\iff C_{M,T}(x)=C_{M,T}(z)$，信息粒是 T 中满足该
关系的全部观察者样本。边界冻结后相同规则用于测试样本归粒，但测试样本不进入
计数。不同 ToM 来源的同号 bin 不是同一粒；两个不同粒回退到同一父概率，也不
意味着把其 phase/nW 身份合并。

### 5.1 M1 的训练内分箱

每个当前训练集合、每个 b=(phase,nW) 独立拟合：

1. 请求 B∈{1,3,5}。B=1 明确为当前模型的 M0 层，不额外重复收缩。
2. 对训练 r，用权重 u 的经验分布 $F_{T,b}$，切点为左逆
   $c_l=\inf\{z:F_{T,b}(z)\ge l/B\}$。
3. 重复切点合并；等于训练最大值的切点删除，避免空的上尾箱。训练最小值上的
   同值原子可保留，随后仍须满足支持门槛，不拆相同 r。
   约定首箱 `(-inf,c1]`、中间 `(cl,c(l+1)]`、末箱 `(c_last,+inf)`；实际输入
   仍须满足合法 Q 约束，不裁剪 r 或对 Q 重归一化。
   测试 r 超出训练范围时进入端点箱，不借测试数据重新分箱。
4. 只依据训练属性支持合并：每叶要求 distinct games≥10 且 H_C≥5（浮点比较容差 1e-12）。
   从最左不满足的叶开始，与相邻加权质量较小者合并；并列选左，端点只有一个邻居。
   重算支持并重复，直到全部满足或只剩一叶；只剩一叶直接返回 b 层。
5. 支持判断/合并不使用 Y。不得因“没有负类”而删除、拆分或重排该粒。

M0 的 b 层可以稀疏，不强制把不同 phase/nW 的等价类合并；稀疏性通过父层
平滑处理。不同 b、不同 f_k、不同 CV 训练集合的切点均独立保存。

## 6. 概率估计与回退

判断：训练内等价类适合作为透明、可审计的首个 DTRS 概率基线，但分段常数表示
会损失 r 的连续信息，硬边界和稀疏性也可能损害校准。相同粗化属性并不意味着
隐藏认知状态完全相同；估计的是该粒内的平均事件概率。是否有预测增益必须由
M0–M1 配对结果检验，不能因其形式符合 DTRS 就预设优于简单基率或连续概率模型。

原始经验频率简单透明，但本数据的单类别及极小支持粒很常见，直接输出 0/1
会导致错误例的无穷 Log Loss。建议保留其为次要消融，主模型使用层级收缩：

\[
p_{root}=(S_{root}+1/2)/(E_{root}+1),\qquad
p_C=(S_C+\lambda p_{parent(C)})/(E_C+\lambda).
\]

层级路径为 `global → nW → (phase,nW) → r-bin`，M0 在 b 层停止。
同一模型所有非根层共用 λ∈{.25,1,4}，单位是 game-equivalent mass。
根层伪计数保证有限概率；未见粒返回最近已观察父层，未见 b 回退 nW，未见 nW
回退 root。合法输入缺失或非 canonical phase 则报错，不伪造其他状态。

单类别粒保留并收缩；细粒支持不足优先执行上述训练内邻箱合并，再走层级回退。
父层可由同一批训练数据估计。这是明确的**加权正则化收缩规则**，不是在局内
独立性和完整层级生成模型均未建立时的“精确 Beta–Binomial 后验”。不从行数
构造看似精确的独立 Beta credible intervals。

### 6.1 选参规则

M0 仅选 λ；M1 选 (B,λ)，共 3 和 9 个候选。每个候选仅用当前内层训练集构造，
在三个内层验证块收集的 240 局逐局 Brier 上等权平均。每次从头学习边界/父概率。
差异≤1e-8 视为并列，选更少请求箱数，再选更大 λ。不得根据外层分数改网格。
M0/M1 分别选参，主比较对应两种完整开发流程；若要纯隔离“增加 r”的效应，
可额外报告共用 M0 λ 的次要消融，但不替换主结果。

次要 OBS-EF 可在同一训练粒结构上输出不平滑频率，记录 0/1 比例；它不用于决定
主模型的结构。可选补充 `OBS-LR-r`：phase×nW 截距加连续 r 的正则 Logistic，
用于检查硬边界/分箱信息损失。拟合、标准化和惩罚选择同样只在训练/内层进行；
若纳入，预先限定 r 的两个 nW 斜率、非截距 L2∈{.001,.01,.1,1}，不强加单调。
具体为全局截距加三个 b 虚拟变量及两个 nW 的 r 斜率；仅全局截距不惩罚。
按训练加权均值/方差标准化 r，方差为零时 z=0；最小化
$|T|^{-1}\sum u\ell+\tau\|\beta_{nonintercept}\|_2^2/2$，内层同样按 Brier 选 τ。
全训练集若为单类别则使用根层平滑常数，不让不受罚截距发散。
它是同一 Y 的概率基线，不替换三支认知语义，也不冒充历史 Phase2 Mapper。

## 7. 主指标、校准和配对比较

外层测试游戏 g 的两个主概率分数：

\[
BS_g=\frac1{n_g}\sum_j(p_{gj}-Y_{gj})^2,
\quad LL_g=-\frac1{n_g}\sum_j[Y_{gj}\log p_{gj}+(1-Y_{gj})\log(1-p_{gj})].
\]

总体先逐局平均，再对 1500 局等权平均；二分类 Brier 不另乘 2，LL 用自然对数。
主终点为 $\Delta BS=G^{-1}\sum_g(BS_g^{M1}-BS_g^{M0})$，负值更好；LL 同法作
次要对比。保存逐游戏、逐来源 fold 和逐状态分数，不用记录级 t-test。
Brier/Log Loss 是 proper scoring rules；方法依据见 [Gneiting & Raftery 原文](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)。

仅计算 LL 时用 ε=1e-12 防止数值 log(0)，记录触发比例；预测文件保留原概率，
Brier/校准图也用原概率。主平滑模型正常不应触发。未平滑 EF 的零概率错例数
单列报告，不用裁剪后的有限 LL 掩盖这一问题。

校准：固定概率区间 `[0,.1),...,[.9,1]`，按相同 u 汇总平均预测与正例率，附行数、
游戏数及游戏质量；报告整体 `mean(p−Y)` 和加权 ECE。ECE 不是唯一选参依据或
校准证明；小样本分箱可能掩盖失校准，参见 [Vaicenavicius 等原文](https://proceedings.mlr.press/v89/vaicenavicius19a.html)。
主方案不对外层结果再拟合 Platt/isotonic。校准差也必须如实记录。

对子组 H，主测度的条件分数用
$\sum_g n_g^{-1}\sum_{j\in H}\ell_{gj}/\sum_g n_g^{-1}n_{gH}$。
若另报“子组内逐游戏等权”，必须单列其定义，不能与前者混称。
成功空/非空报告仅作事后审计子组，仍包含于主总体；不在上线接口中用该未知标记
分流。当前空报告全正，不能从该组表现推断模型识别了狼人身份。

## 8. 不确定性与证据强度

保存每局 M0/M1 配对分数后，按 `(ToM fold, downstream outer fold)` 的 25 个
固定块，各自有放回抽取 60 个**完整游戏**，保留 M0/M1 配对与局内全部样本。
使用 PCG64、seed=20261014、2000 次；报告 percentile 95% 区间，quantile method=linear。
遍历顺序固定为 replicate 在外、(k,j) 字典序在内，各块 game_id 排序后执行
`rng.integers(0,60,size=60,dtype=int64)`；同一索引同时用于两模型和全部指标。
保存 NumPy 版本、抽样索引摘要和每次有效覆盖，不为某一指标单独重抽。
同法对校准曲线重采样，少于 20 游戏支持的点不画置信带；空箱 NA，少于 95%
有效重采样的箱也标 NA，不据测试标签合箱。

这是**固定已拟合预测下、病例组成变化的近似稳定性区间**。CV 训练重叠、ToM
共享训练集及模型选择会引入额外依赖；该 bootstrap 不重训任何模型，不覆盖
ToM/DTRS 拟合和选择方差，不是端到端算法风险的严格置信保证。不能只重采样五个
fold，或重采样观察者行来夸大独立样本量。
若需要条件于固定 f_k 的训练算法方差，应另设计按原 game ID 保持重复样本同折的
整流程重采样并重做 DTRS 选参/拟合；若需要完整端到端方差，还须隔离并重做 ToM
及全部选择。本轮不执行这些扩展。

## 9. 验收和实验边界

工程验收不以 M1 必须胜过 M0 为条件：

1. 数据集/版本/源码/ToM来源全部钉住；每个下游训练/选择/测试游戏均在同一 F_k，
   且与对应 ToM 训练游戏无交集。
2. 25 个外层块覆盖每局/样本一次；同局所有记录同折；内层和外层边界均可重建。
3. 改外层测试 Y 不改变预测/选参/边界；改内层验证 r 不改变该内层训练边界；
   同 r 不拆分；改变监督支持/空报告标记不改变在线属性接口。
   这些非干预测试应对已验证后内存中的分区对象执行；仅因修改正式文件导致
   artifact 校验报错，不能冒充统计隔离测试。当前冻结 ToM 的历史 RNG 非干预
   不满足，须明确作为来源限制，不能用 D2 单元测试掩盖。
4. 未见、极小、单类别粒与单狼 dW=None 均有测试；每条预测是有限合法概率，
   无静默丢弃；父层和细粒支持、回退次数、λ、边界与权重归一化完整保存。
5. 在可人工核对样例上验证游戏/记录权重、分箱、回退、Brier/LL 和配对重采样。
6. 报告总体、phase×nW、空/非空、ToM fold 的覆盖/分数/校准/支持；无负类组保留。
7. 发现 M1 无增益、回退过多或校准恶化可以是合格结果，不事后重定义目标或删组。

开发阶段若 ΔBS<0 且其近似区间上端<0，可称“固定来源和该开发协议下有增益
证据”，同时给 LL 与子组代价；不得升级为端到端独立显著性结论。M2/M3 为扩展
探索，不在看到主测试结果后反复调参并沿用同一置信声明。

端到端独立泛化要求：新游戏未进入任何 ToM 训练、数值 seed/来源哈希、预处理拟合、架构/检查点选择、
DTRS 训练/分箱/选参/校准或研究方案选择；在线 ToM 与概率映射来源匹配；容量、
失败处理和主指标提前固定。当前历史 1500 局不足以独自提供此种证据。
这不要求立即重训 ToM：若采用从未进入旧 publication/hash 或选择过程的真正新增
外部游戏，可在看到其监督前冻结**已有 ToM + 与之匹配的 DTRS + 全部选择与失败
处理**，再独立评价冻结管线。该结果仍不是完整重训算法方差的估计。
若要修复历史训练过程的强隔离，则需未来另授权采用数据无关数值 seed，并将全部
训练/选择纳入外层协议；本轮不修改冻结训练实现或重新发布旧预测。
