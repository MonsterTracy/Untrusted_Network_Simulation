## 1. 两处协议差异已解决

D3a §7要求主比较 EQ1−EQ0，次要 LR−EQ1、EF−EQ1；D3d-1只有相对EQ0的三个比较。

| 比较 | 研究角色 |
| --- | --- |
| OBS-EQ1−OBS-EQ0 | 主模型比较 |
| OBS-LR-r−OBS-EQ1 | 关键次要比较 |
| OBS-EF−OBS-EQ1 | 关键次要比较 |
| OBS-LR-r−OBS-EQ0 | 补充 |
| OBS-EF−OBS-EQ0 | 补充 |

role 标识模型比较关系；只有主策略/游戏等权是主分析，其余策略与权重属于敏感性。

## 3. 等价性能优化，没有改变指标

`d3_runner.py` 中缓存运行期解码视图与训练支持视图，避免在逐样本循环重复解析完整协议JSON；
预计算六个固定行动/标签损失值与重复概率的精确风险字符串；行级结果仍各自持有独立字典。
每组四模型比较完成后释放逐游戏中间表，仅保留成本邻接需要的90份主EQ1区域映射。
Bootstrap缓存的是同一原索引的2000个重复估计，不是区间端点；同组模型比较复用后释放。

新增 `d3_stability.py` 只优化既有扰动**摘要**，实际区域仍调用原 `decide` 的精确Fraction argmin。
原 D3b `decision.py` / `decision_offline.py` 未修改。精确等价依据：

1. 对仿射风险和固定全序并列规则，选中行动a的集合是若干严格/非严格线性半空间的交，故在一维为区间。
   扰动区间两个端点选同一行动，当且仅当整段选择稳定。
2. 固定在原p选中的行动a，regret(eta)=R_a(eta)−min_b R_b(eta) 是仿射差的最大值，故为凸函数。
   区间最大值出现在端点。

因此稳定布尔量和最大情景后悔值只需两个端点的**精确风险与argmin**，无须反复构造完整阈值/摘要。
它没有阈值近似、概率舍入、吸附或扩大BND，也不把Y或支持交给决策。
自动测试对全部45成本、三并列序、弱序/退化诊断、精确边界及nextafter、四半径逐项对照原枚举实现。

另保留了D3d-1人工封存作为独立版本对照：新运行器全部720份case载荷SHA-256与原记录**完全一致**。
八组压力样例的优化前后载荷摘要也一致，包括22685条概率全异样例。

建议预算：

- 正式启动前仍需由用户手动检查服务器可用CPU/RAM/磁盘与现有服务，不能将本机压力测试当服务器验收。
