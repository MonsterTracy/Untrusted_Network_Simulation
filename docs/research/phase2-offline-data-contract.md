# Phase-2 offline data and reference values

`werewolf.phase2_offline.build_development_layer(publication_path, evaluation_root)` is a read-only builder. It verifies the fixed 1,500-game publication, restricted role sidecar, five-fold assignment, and sealed Qwen3 OOF prediction artifacts before returning in-memory candidate rows, post-day states, and reference tables. It fails when the retained PRE, candidate, post-day, or skipped no-candidate PK PRE populations differ from 5,761, 21,638, 3,317, or 74. It does not publish an artifact or run a predictor.

Each candidate is identified by `(game_id, boundary_id, acting_wolf, phase, candidate_j)`. `theta_ac` is the positive, tied-maximum normalized breadth among the phase competition targets, computed only from valid canonical non-wolf suspicion reports. For this complete-case publication, the label observer set must equal the runtime-legal set of living non-wolves excluding the target. A missing report or empty panel fails explicitly.

`R2Input` contains `(mu, delta, sigma, h, phase, audience_size, competition_size, remaining_speakers_before_vote)`. `mu`, target-specific `delta`, and population `sigma` use raw OOF probability mass on the frozen six non-self support; they never renormalize for living or competing targets. Only entropy conditions each observer's row on the current competition set minus self. One-target entropy and one-observer population standard deviation are zero by definition; the latter does **not** imply agreement. Zero competition mass fails. Speaking position comes from the current public PRE's cyclic phase speaker queue, before any future speech or ballot. Under the current rules, its members equal the competition set (alive players in speech, public tie targets in PK), but the queue and competition set have distinct meanings. Neither real suspicion reports nor OOF `q`/`label_observed` enter R2.

The five resolved-day outcome classes are read from the final vote or PK exile result. The intermediate empty exile preceding PK is not `no_exile`. Each `CandidateRow.s_pre=(n_W_pre,n_NW_pre)` comes from that PRE's alive set and restricted wolf-team truth; it is loss/evaluation metadata, **not part of mapper Z**. The resolved-outcome transition `tau(s_pre,Y)` applies the final exile once: non-wolf exile subtracts one non-wolf, wolf exile subtracts one wolf, and no exile leaves counts unchanged. The resulting `s_post` must equal the post-day `S0=(n_W_post,n_NW_post)` captured after final exile and the terminal check, once per completed game/day. The final game winner labels empirical continuation outcomes.

`V_ref_pub` means **reference continuation value under the policy that generated the development publication**. Terminal cells use the game rule. A nonterminal cell uses the mean final WolfWin over its `(game,day)` state visits; repeated visits from a game are not independent observations. A development game's cross-fitted table excludes its entire fold. The full-development table uses all five folds and is kept separate for future deployment lookup. Each empirical cell records its excluded fold, training-game count, state-visit count, unique-game count, wins, and mean. Unobserved nonterminal cells fail, with no smoothing or fallback.

`ReferenceTables.development_loss(game_id,s_pre,Y)` selects and verifies the game's excluded-fold table; `deployment_loss(s_pre,Y)` selects and verifies the full table. The low-level table-taking loss helper is private. Both return `1 - V_ref_pub(tau(s_pre,Y))`. **Post-day S0 is the value-table state, never the pre-outcome loss argument.** The five mechanism outcomes map to three team-count transitions. This is a reference lookup, not an action-conditioned effect or a value for a future TWD policy.

The large-artifact regression test is opt-in through `PHASE2_PUBLICATION_ROOT` and `PHASE2_OOF_ROOT`; ordinary tests use small synthetic records.
