# Observer-DTRS v1 D2a：统计方法来源与适用边界

日期：2026-10-14。本文仅核对方法依据，不声称重新验证项目数据或历史训练过程；具体来源审计与数值以 D2a 主协议为准。以下数学推导和协议选择属于本项目建议，不能理解为引用论文已经证明本项目的独立泛化。

## 1. 两层训练的隔离：本项目推导

先作理想化前提：完整游戏集合分为五个 ToM fold $F_1,\ldots,F_5$，冻结预测器 $f_k$ 的训练及监督选择均不使用 $F_k$。对于 $g\in F_k$，OOF 特征由 $f_k$ 生成。单条 OOF 的训练游戏排除，本身不能证明所有选择与数值控制也排除了该游戏监督。

如果对全部 OOF 特征再次任意划分 DTRS 训练/测试游戏，则对测试游戏 $b\in F_k$、训练游戏 $a\in F_l,\ l\ne k$，可能存在路径：

\[
\text{游戏 }b\text{ 的 ToM 监督信息}
\longrightarrow f_l
\longrightarrow Q_a
\longrightarrow \text{DTRS 拟合}.
\]

这里的风险来自 ToM 报告监督与新目标标签共享游戏内隐状态，并不要求两层标签完全相同。因此不能仅凭每条 Q 是 OOF，宣布后续任意游戏交叉验证端到端独立。这个具体依赖路径是项目推导。一般原则是所有拟合、预处理和模型选择都应隔离测试数据；官方文档还明确要求先划分，再在训练子集学习变换。[scikit-learn：数据泄漏与训练集预处理](https://scikit-learn.org/stable/common_pitfalls.html#data-leakage)

在每个 $F_k$ 内单独按完整游戏进行 DTRS 外层 5 折、每次 240 局训练/60 局测试，再仅在该 240 局内做 3 折选择，可以在固定 $f_k$ 条件下切断上述路径。代价是每个下游模型只能用 240 局，稀疏 PK 信息粒尤其受限；五个预测器及下游模型也不能当作五次独立重复实验。模型选择本身会过拟合有限的验证数据，最终评价须与选择分离。[Cawley & Talbot, 2010，JMLR 原论文](https://www.jmlr.org/papers/v11/cawley10a.html)

该方案还要求审计：ToM 检查点、早停、超参数及预处理是否接触 $F_k$ 的监督。如果 Qwen3 架构或研究方案曾根据全部 1500 局 OOF 成绩选择，本轮仍应称“下游概率模型开发验证”。只有新的外部游戏，或将所有训练及设计选择嵌入外层隔离的完整重训，才支持更强的端到端独立泛化主张。

本轮实际审计发现：历史训练 `_reset_rng` 使用的数值 seed 包含 preparation 摘要，
后者绑定全量 publication（含 held-out 报告）。因此上面的强隔离前提在现有
产物中并不成立；fold 内方案只能消除经其他 fold 训练输入的直接路径，不能修复
已封存权重的来源哈希→RNG 依赖。机械哈希依赖不证明模型有效利用标签或造成
乐观偏差；本轮没有测量其性能影响。源码版本、函数与五折实际绑定见
[主协议 §2](observer-dtrs-v1-d2a-protocol.md#21-来源事实) 及诊断 JSON。
真正新增且未参与旧哈希/训练/选择的外部游戏，可在整条管线提前冻结后独立评价
已有 ToM，无需为了这个外部固定管线测试立即重训 ToM。

## 2. 分箱、平滑与统计目标：本项目定义

M0 的信息粒由 `phase × nW` 确定；M1 再加入训练游戏确定的 `bin(r)`。每次内层验证必须重新学习分箱，选定参数后再用全部外层训练游戏重学；测试阶段只应用保存的边界。相同 r 不拆到不同箱，重复边界合并。以上 train-only 约束遵循前述官方预处理原则，具体分位数及箱数是本项目待冻结的协议。

记录等权对应从全部合法样本中抽样；游戏等权对应先均匀抽一局，再在该局合法样本中均匀抽一条。令 $n_g$ 为游戏的全部合法样本数，游戏等权为 $w_{gj}=1/n_g$，则某信息粒 $C$ 的条件频率为：

\[
\widehat p_C=\frac{\sum_{g,j}w_{gj}1\{x_{gj}\in C\}Y_{gj}}
{\sum_{g,j}w_{gj}1\{x_{gj}\in C\}}.
\]

不要改为粒内每局重新归一化，后者定义了不同的条件分布。推荐以层级收缩形式补充原始频率：

\[
\widetilde p_C=\frac{S_C+\lambda p_{\mathrm{parent}(C)}}{W_C+\lambda}.
\]

未见粒直接使用父层；小支持或单类别粒保留但收缩；单狼的 dW 为不适用，不填入数值 0。父概率、阈值和超参数均仅来自当前训练游戏。使用分数游戏权重及同源父估计时，这个公式是确定性的加权收缩估计，不能未经额外生成模型假设就称其为精确 Beta–Binomial 贝叶斯后验。支持应同时报告原始行数、独立游戏数和加权质量，不能把行数当独立证据数。

## 3. 评价与校准

采用游戏级平均 Brier 和 Log Loss：先在每局合法记录上平均，再对游戏等权平均；主要比较同一游戏上的 M1−M0 差值。Brier 的二分类定义固定为 $(p-y)^2$，Log Loss 用自然对数。两者都是严格 proper 的概率评分，评价概率质量比仅报告分类正确率更符合本任务。Log Loss 对接近 0 的错误预测尤其敏感，原始频率的单类别粒会造成无穷损失，应显式报告边界预测与数值策略。[Gneiting & Raftery, 2007，作者提供的 JASA 原论文，§3 与表 1](https://sites.stat.washington.edu/raftery/Research/PDF/Gneiting2007jasa.pdf)

校准图应给出固定概率区间内的平均预测、实际正例率、行数和游戏数；主要图采用与主评价一致的游戏权重。ECE 受分箱影响，分箱还可能掩盖更细的失校准，不能把低 ECE 当校准证明或唯一选择指标。[Vaicenavicius et al., 2019，AISTATS 原论文，§4–5](https://proceedings.mlr.press/v89/vaicenavicius19a/vaicenavicius19a.pdf)

成功空报告应维持既定标签定义，其表现可以作为审计子组报告。该状态是受限监督信息，不是部署时可以分流的输入，也不能因为该组全正就从总体评价中删除。

## 4. 不确定性的严格边界

按完整游戏有放回抽样，并将 M0、M1 的同一游戏记录一起抽样，可保留局内相关性和模型比较的配对关系。成对 cluster bootstrap 的基本单位是整簇，不是逐行独立抽样。[Cameron & Miller, 2015，作者提供的 JHR 原论文，§II.F](https://cameron.econ.ucdavis.edu/research/Cameron_Miller_JHR_2015.pdf)

本项目建议在每个固定 `(ToM fold, DTRS outer fold)` 块内重采样完整游戏，再汇总预先保存的游戏分数差；不能只重采样五个 fold。这样的区间只能描述固定来源、固定划分及已拟合预测的条件性评价变动。由于交叉验证训练集重叠，逐游戏 OOF 分数之间仍有拟合依赖，简单 percentile 区间不是完整训练算法风险的严格置信保证；它没有重训 ToM 或 DTRS，也不包含分箱/平滑选择及共享预测器训练方差。若要估计完整算法不确定性，需要在适当外层隔离中重做选择和拟合，不能通过增加固定分数 bootstrap 次数代替。

本文引用的是方法依据；240/60、内层 3 折、具体平滑层级、参数网格和 bootstrap 次数均是项目协议选择，需要在正式运行前固定并记录，不能宣称为文献给出的唯一方案。
