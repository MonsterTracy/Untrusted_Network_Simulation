# Include the speaker turn boundary in PRE input

The canonical PRE input is the cumulative public history ending with the observer-visible `turn_start(current_speaker)` event, followed by Belief Observation and only then the current speaker's public speech. The terminal Speaker Turn Boundary is therefore a model-visible authoritative public event; the subsequent speech and its derived V1 Speech Actions remain strictly excluded. Canonical construction must emit this complete prefix, and Dataset must encode it without deleting the boundary. This intentionally replaces the historical R0 behavior that retained the boundary in snapshots but stripped it during Dataset construction. The new contract requires a distinct semantic/version identity and no R0 compatibility path. Any other upcoming-speaker representation must be justified as semantically distinct or removed to avoid duplicate encoding of the same public fact.
