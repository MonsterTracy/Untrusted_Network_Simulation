# Retain Night0 without exposing private scheduler phases

The formal Classic7 environment retains Night0 because existing baselines and canonical data use the opening sequence Night0, public night result, then Day1 discussion; removing it would change the game and data distribution during an architecture reconstruction. Canonical public history begins with `(day=0, phase=night)`, so the first death announcement has a causal temporal state before Day1. The complete observer-visible Public Phase ontology is `night`, `discussion`, `vote`, `pk_discussion`, and `pk_vote`; death announcements inherit `night`, while vote and exile results inherit the normal or PK vote phase that produced them. Public Phase Transitions must never reuse internal role-action scheduler names such as wolf, Seer, or Witch skill phases.
