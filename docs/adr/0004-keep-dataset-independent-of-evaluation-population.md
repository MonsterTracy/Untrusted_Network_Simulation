# Keep Dataset independent of evaluation population

The Dataset has one public-only tensorization and one current belief-target semantics, but no knowledge of evaluation populations, Role Sidecars, role filters, private conditioning, or selectable target sources. It produces Canonical ToM Samples containing public model tensors, targets, Belief Observation status, Observer Alive State, and causal audit metadata. Fixed operations combine externally derived Observer Eligibility Masks with observation status: the Primary mask controls training and Primary evaluation, while the all-alive mask is evaluation-only and is applied to the matching Primary-trained checkpoint. Supervision-control metadata may accompany dense batches for orchestration but is never passed to or interpreted by model representation computation, so both evaluations share Dataset primitives without recreating a generic population interface.
