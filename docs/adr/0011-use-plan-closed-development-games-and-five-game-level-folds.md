# Use plan-closed development games and five game-level folds

The current development protocol uses the complete Development Game Set produced by a predeclared Canonical Collection plan with an ordered seed pool, attempt-once and no-rerun behavior, and a target canonical-success count. Development Publication includes every success that reaches the target without retrospective filtering, and assigns whole games deterministically to exactly five versioned OOF folds so all PRE Boundaries from one game stay together. Historical 48/6/6, 54/6, sealed-split semantics, hard-coded game counts, arbitrary subsets, and runtime fold-count choices are excluded. A future final paper evaluation may define a new preregistered Final Evaluation Publication over independent data, but cannot be introduced as a temporary test subset of the current development lineage.
