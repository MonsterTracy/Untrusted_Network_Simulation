# Use game-macro as the headline evaluation estimand

Primary Development OOF and All-Alive Identifiability Stress use one headline aggregation estimand: derive the operation's score within each held-out game from that game's effective-supervision rows, then average those per-game scores with every game weighted equally. Five-fold OOF exists to obtain held-out predictions for every game; folds are not statistical weighting units. Uncertainty uses a game-cluster bootstrap that resamples games with replacement and recomputes the identical game-macro estimand in every replicate. Observer-row-weighted results may remain explicitly named secondary diagnostics, but they cannot become a second primary result or be paired with game-macro confidence intervals. This prevents longer games and games with more surviving observers from silently dominating the headline result and aligns aggregation, fold identity, and the independent collection unit.

The score computed inside each game is the arithmetic mean of row-level belief divergence `D_KL(q || p)` over that operation's effective-supervision rows; lower is better. This removes target entropy from model error and remains defined for both non-empty and Successful Empty Belief Observations. A Uniform Non-Self Reference must be evaluated on the identical rows with the identical game-macro aggregation. Cross-entropy, total variation, absolute-error, support-based, observer-row-weighted, and normalized reducible-gap results are explicitly secondary diagnostics. Normalized reducible-gap improvement cannot be the headline because Successful Empty Belief Observations have zero reducible gap relative to the Uniform Non-Self Reference, making a baseline-relative ratio unstable as the overall primary score.

Primary training uses Game-Balanced Belief Cross-Entropy. Within each training game, cross-entropy is averaged over Primary effective-supervision rows; the resulting per-game losses are then averaged equally across games in a minibatch. All-Alive rows never enter training. Observer eligibility and observation status select supervision only and never enter model representation. A training game with no Primary effective-supervision row fails closed rather than disappearing from the objective. Cross-entropy remains the optimization quantity while belief KL remains the headline evaluation score; their per-row gradients differ only by target entropy, which is constant with respect to model parameters.
