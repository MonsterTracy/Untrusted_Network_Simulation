# Require full PRE-prefix tensorization

Capacity is a predeclared training setting chosen without consulting held-out content. Whole-publication statistics validate that declaration; they do not automatically select or enlarge it. Overflow fails closed and does not authorize adapting the same formal run to held-out data.

Every Authoritative PRE Prefix must be tensorized in full. Development Publication records its Maximum Structured Token Count, and before training an immutable experiment manifest must bind a `max_seq_len` greater than or equal to that count. Dataset and feature construction treat this value only as a capacity and validation bound; any overflow fails closed. Silent left or right truncation, recent-event windows, daily reset, history compression, token dropping, and dynamic extension during training or evaluation are prohibited. Corresponding Implicit Temporal and Explicit Day/Phase lineages use the identical complete token sequence and the same `max_seq_len`. The historical `256` value remains valid only for a publication whose every prefix fits; increasing the bound for longer canonical data is an explicit model/input configuration change, not an invitation to enlarge learned model capacity or copy ONUW.
