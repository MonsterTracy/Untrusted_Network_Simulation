# Treat ONUW as a principle-level methodological reference

ONUW is retained only as the methodological source for transforming natural-language social interaction into chronological subject-action-object structure and using a Transformer to predict observer-conditioned player-belief distributions. It does not impose its five-player, single-night or single-day setting, rounds, multimodal inputs, exact ontology or schema, current-speech timing, repeated per-action supervision, private-role conditioning, tensor dimensions, model size, training schedule, metrics, interfaces, or implementation quirks. Classic7 strict PRE causality, cumulative multi-day public history, V1 perception, public-only input, and seven-player belief output always take precedence, and no ONUW parity adapter or compatibility path may be introduced.
