# Use a fixed non-self suspicion simplex

Every observer-specific belief target and prediction uses a seven-position player axis but belongs to the fixed Non-Self Suspicion Simplex: the observer's diagonal entry is exactly zero and the other six entries sum to one. A successful non-empty suspicion support must exclude the observer and is converted to a uniform distribution over its members; a Successful Empty Belief Observation assigns `1/6` to every non-self player. Reporter self-suspicion is a semantic failure and therefore triggers Complete-Observation Canonicality failure if bounded attempts are exhausted. Model normalization structurally excludes the diagonal for both Non-Wolf and Werewolf observers, because the task models the observer's reported suspicion over other players rather than a probability of the observer's own true role. Diagonal exclusion is one immutable output contract, not a Dataset, model, or CLI option.
