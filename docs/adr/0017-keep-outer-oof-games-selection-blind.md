# Keep outer OOF games selection-blind

Every outer OOF fold is completely selection-blind. Its games cannot influence epoch selection, early stopping, learning-rate adaptation, hyperparameter or configuration choice, model selection, or retry and rerun decisions. Each fold checkpoint must be determined solely from the outer-training games and a training protocol frozen before outer evaluation. Only after checkpoint identity and digest are immutable may the system evaluate Primary Development OOF on the outer games and then apply that exact checkpoint to All-Alive Identifiability Stress. Observing either outer result cannot change the checkpoint. This replaces the historical path that selected `best.pt` using the same held-out fold later reported as OOF and is required for the combined held-out predictions to support an unpolluted Game-Macro Estimand.

The selection-free protocol is fixed-budget training over all four outer-training folds, without inner validation or data-dependent early stopping. Before any outer-fold evaluation, an immutable experiment manifest records the epoch or optimizer-update budget, optimizer, scheduler, batch construction, initialization seed, and all other training parameters. Corresponding Implicit Temporal and Explicit Day/Phase lineages use the same budget and protocol. Training emits one fixed-budget terminal checkpoint rather than a `best.pt`; curves and Memorization Sanity may diagnose implementation behavior but cannot trigger extra epochs, retraining, or checkpoint replacement in a formal run.
