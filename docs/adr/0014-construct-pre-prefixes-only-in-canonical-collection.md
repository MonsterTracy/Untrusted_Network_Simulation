# Construct PRE prefixes only in Canonical Collection

Canonical Collection is the sole authoritative constructor of each PRE input prefix. It freezes the cumulative public history after `turn_start(current_speaker)` and before any current-speaker speech, binding the PRE Boundary identity, public-event cutoff, and digest into canonical evidence. Development Publication, Dataset, and deterministic replay may independently validate identity, order, cutoff, coverage, digest, and speech exclusion, but may only consume the frozen prefix without cropping, completing, reordering, repairing, or semantically reinterpreting it. Defensive validation at several handoffs is intentional and is not duplicate transformation. Physical storage of the prefix is deferred, but no storage choice may create a second accepted PRE-construction path.
