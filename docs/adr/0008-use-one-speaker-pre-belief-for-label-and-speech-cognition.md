# Use one speaker PRE belief for label and speech cognition

At each PRE Boundary, Canonical Collection obtains one Belief Observation from every alive observer. The current speaker's successful observation is frozen as the unique Speaker PRE Belief and handed back to that same playing agent for the immediately following speech cognition; the agent may not resample a second wolf-belief estimate for the same PRE-to-speech transition. Non-speaker observations remain labels only. This Speaker PRE Belief Handoff preserves one cognition source for supervision and behavior and is part of canonical data generation, while trained ToM predictions remain permanently excluded from gameplay generation and control. A failed speaker observation cannot be replaced by a silently resampled belief.
