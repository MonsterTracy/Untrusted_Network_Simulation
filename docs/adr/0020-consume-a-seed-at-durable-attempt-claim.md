# Consume a seed at durable attempt claim

Canonical Collection uses an append-only Canonical Collection Attempt Ledger. Before any gameplay or backend call for a planned seed, it durably claims that seed; the claim is the formal start of its single permitted attempt. A claimed seed is permanently consumed under that Collection Plan identity whether it ends as a canonically eligible success, a normal failure, or a process interruption. On resume, any claimed attempt lacking a completed terminal record is closed as `interrupted_failure`, retains all recoverable partial and failure evidence, and is never rerun or replaced with another game under the same seed. Resume verifies the immutable plan identity and digest, ordered seed pool, runtime, parser, backend, retry-budget provenance, ledger uniqueness and order, and existing artifact digests; mismatch fails closed and requires a new plan or run identity. Previously eligible successes count toward the target, and collection continues from the next unclaimed seed. A crash before durable claim leaves the seed unattempted. Atomic claim mechanics and physical ledger layout are deferred to the implementation specification.
