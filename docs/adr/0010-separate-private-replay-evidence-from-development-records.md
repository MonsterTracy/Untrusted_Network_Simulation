# Separate private replay evidence from development records

Canonical Game Bundles retain Private Replay Evidence when it is required for deterministic replay, canonical validation, and provenance-bound Role Sidecar derivation. Development Publication must strip observer-private observations, hard knowledge, checks, teammate knowledge, and role identifiers from published public-history and Belief Observation records; Dataset, tensorization, and model forward never receive them. Development Publication may read private evidence only to verify canonical provenance and to extract the complete game role assignment into the already restricted Role Sidecar, which cannot contain observer hard-knowledge histories or become a private-conditioning source. Exact artifact layout and validation interfaces are intentionally deferred to the implementation specification.
