# Separate canonical game evidence from development publication

Canonical Collection publishes one immutable Canonical Game Bundle per game containing authoritative public events and raw speech, V1 annotations, strict-PRE Belief Observations and statuses, submitted actions, call and parser audits, replay provenance, private replay evidence, identity and digests, and Canonical Eligibility. It never performs target conversion, tensorization, temporal representation, population selection, folds, training, or evaluation. A Development Publication consumes only canonically eligible bundles, verifies their identities, digests, replay and PRE coverage, freezes the development game set, and publishes public development records, game-level folds, a provenance-bound Role Sidecar, and a lineage manifest. Dataset and training consume a declared Development Publication identity rather than traversing or selecting arbitrary collection directories.
